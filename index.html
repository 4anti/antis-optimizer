CLI reference

Every flag runs locally via Node 18+ or one npx command with zero install step.

  1. --audit

    Counts source vs junk, flags files over 15 KB, and recommends the lightest setup tier.

  2. --detect

    Discovers installed coding agents, MCP servers, and nested worktrees.

  3. --sync-ignores --write

    Keeps .ignore, .contextignore, and MCP exclusions aligned in one pass.

  4. --outline <file> [filter]

    Extracts exact symbol bounds via TypeScript Compiler AST or built-in lexer.

  5. --slice <name> [key]

    Reads only one bounded symbol range or structured section under strict byte caps.

  6. --sync-landmarks && --verify

    Auto-heals shifted doc line pointers and validates caps in one output line.
