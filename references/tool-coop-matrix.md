# Tool & Hook Cooperation Matrix

Load on demand when setting up `antis-optimizer` alongside MCP servers, plugins, or local hook optimizers.

| Layer / Tool | Active Scope | Exact Interaction with `antis-optimizer` | Co-op Rule |
| :--- | :--- | :--- | :--- |
| **`jcodemunch` MCP** (`counter` 6-tool door) | Claude Code (auto-hooks) + Antigravity (manual `register_edit`) | Ignores `.ignore` (reads `.gitignore` + `.jcodemunch.jsonc`). Emits **0 AST symbols** for inline `<script>` in `.html` (`HTML_SPEC`) and `.md`. Slower than native `Grep`/`Read` on small repos / known lines. | Sync `.jcodemunch.jsonc` `extra_ignore_patterns`. Route code callers/blast radius to `jcodemunch` (overriding Ponytail's generic "grep every caller"); keep HTML/JSON monoliths & domain IDs in `repo-index`. |
| **`Token Optimizer` hooks** (`read_cache`, `archive_result`, `bash_compress`) | **Claude Code ONLY** (disabled on Windows Antigravity `os.name == "nt"` & absent on Codex) | `read_cache.py` checks `.contextignore` only (never `.ignore`). `archive_result.py` truncates MCP replies `>=4,096` chars to `1,500`. `pipeline_analyzer.py` L439 enables `bash_compress` if `node` CLI args contain `.json`. `thrash_guard` nudges on 3 identical calls. | Sync `.contextignore`. Emit `file:L-L` from `--slice`/`--outline` so `Read(offset, limit)` bypasses whole-file `soft_block`. Keep CLI stdout `<3,500` chars and avoid `.json` in `node` args. |
| **`TokenEconomizer`** (`toolprune="auto"`, `loopguard="nudge"`) | Claude Code ONLY | Unused MCP tools across `10` prompts / `2` sessions get written to `.claude/settings.local.json` `permissions.deny`. `repomap_gen.py` ignores `.ignore`. | Keep `repomap="off"` (prefer `--map`). If `repo-index` handles reads cleanly, add critical `jcodemunch` actions to `toolprune_protect` if needed, and keep `--verify` errors deterministic for `loopguard`. |
| **`Ponytail`** (`AGENTS.md`, `ponytail-map.js`) | Antigravity global (`rules/AGENTS.md` 2,721 B, no `hooks/`); optional in Claude | Enforces minimal diff, 1-line *why*, 1 test on risky logic, 1–2 line footer. | **`Caveman` + `/caveman-compress`** | Claude Code (`full` active) | Drops prose filler while keeping code/paths verbatim. `/caveman-compress` modifies `.md` in place. | Never duplicate terse-prose directives in `AGENTS.md`. **Never run `/caveman-compress` on `AGENTS.md`, `INDEX.md`, or `SKILL.md`**. |
| **`Usage Quota` (`autoCompactAt: 50`) + `Context-Mode` pattern** | Claude Code | Compacts at 50% fill; `PreCompact` clears `read_cache`. | Keep Tier-0 docs `<=80` lines so post-compact reload is tiny, and export `--handoff` (`<=2,048 B`) before large tasks/compaction. |

| **OpenCode** (`opencode.json[c]`, `opencode-dcp`, `opencode-ignore`, `openrtk`) | Global `~/.config/opencode/` (`$OPENCODE_CONFIG`, `$OPENCODE_CONFIG_DIR`, `$XDG_CONFIG_HOME/opencode`), repo `.opencode/`, `AGENTS.md` | Uses root `"mcp"` key (not `"mcpServers"`), `"watcher.ignore"`, and `"permission.read"` (ignores `.ignore` unless `opencode-ignore` plugin is loaded). `opencode-dcp` prunes stale tool outputs; `openrtk` compresses shell stdout. | Never auto-create `opencode.json[c]`; when present, `--sync-ignores --write` splices `watcher.ignore` preserving comments, `--verify` checks parity (or `opencode-ignore`) + `.env` `permission.read` deny (`opencode-guard`). |
| **Cursor** (`.cursor/mcp.json`, `.cursorignore`, `.cursorindexingignore`, `.cursor/rules`) | Global `~/.cursor/mcp.json` + repo `.cursor/` | Reads `.cursorignore` (blocks AI reads) and `.cursorindexingignore` (blocks semantic index) separately from `.ignore`. | Conditional sync updates `.cursorignore`/`.cursorindexingignore` ONLY when already present or `.cursor/` exists in repo; sync `.jcodemunch.jsonc` if `jcodemunch` is configured. |
| **Gemini CLI / Code Assist** (`~/.gemini/settings.json`, `.geminiignore`, `.aiexclude`, `GEMINI.md`) | Global `~/.gemini/` + repo `.gemini/` | Reads `.geminiignore` (Gemini CLI), `.aiexclude` (Code Assist), and `GEMINI.md` alongside `settings.json` (`mcpServers`). | Conditional sync updates `.geminiignore`/`.aiexclude` ONLY when present or `.gemini/` exists in repo; keep `AGENTS.md` canonical unless `GEMINI.md` is explicitly required. |

| **Ripgrep (`rg` / native `Grep`)** | OpenCode, Claude, Codex, Cursor, Antigravity | Skips `.dot-dirs/` by default (`--hidden` or explicit dir path required), and Windows `rg` outputs `\` path separators.
