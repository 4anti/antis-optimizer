# Tool & Hook Cooperation Matrix

Load on demand when setting up `antis-optimizer` alongside MCP servers, plugins, or local hook optimizers.

| Layer / Tool | Active Scope | Exact Interaction with `antis-optimizer` | Co-op Rule |
| :--- | :--- | :--- | :--- |
| **`jcodemunch` MCP** (`counter` 6-tool door) | Claude Code (auto-hooks) + Antigravity (manual `register_edit`) | Ignores `.ignore` (reads `.gitignore` + `.jcodemunch.jsonc`). Emits **0 AST symbols** for inline `<script>` in `.html` (`HTML_SPEC`) and `.md`. Slower than native `Grep`/`Read` on small repos / known lines. | Sync `.jcodemunch.jsonc` `extra_ignore_patterns`.
